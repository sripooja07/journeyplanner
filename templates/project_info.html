Crowdedness-Aware Journey Planner

Project Information and Technical Overview

1. Project Overview

The Crowdedness-Aware Journey Planner is a machine learning based web application designed to estimate passenger demand on different bus routes.

The system analyzes historical bus ticketing data and predicts expected passenger demand based on route, date, time and historical travel patterns.

Main Idea: Help passengers identify routes and travel times with comparatively lower predicted passenger demand.

2. Problem Statement

Public transportation passengers may experience inconvenience due to high passenger demand during certain routes and hours. Choosing a suitable travel time can be difficult without information about historical passenger patterns.

This project addresses the problem by developing a machine learning system that estimates passenger demand and provides route recommendations.

3. Project Objectives

  • Analyze historical bus ticketing data.
  • Identify passenger demand patterns across different routes.
  • Predict passenger demand using machine learning.
  • Classify predicted demand into Low, Medium and High categories.
  • Identify comparatively less busy routes.
  • Analyze peak hours and weekly passenger demand.
  • Provide an interactive web-based journey planning system.

4. Dataset Information

The project uses Delhi bus e-ticketing historical data collected for October 2026.

  • Data source: Delhi bus e-ticketing dataset.
  • Time period: October 2026.
  • Original records: Approximately 2.56 million.
  • Target variable: Passenger count.
  • Important features: Route, date, hour, day of week and historical passenger demand.
The dataset represents ticketing demand. It does not directly measure the actual number of passengers physically present inside each bus.

6. Machine Learning Model

The project uses the XGBoost Regression algorithm to estimate passenger demand.

Input Features:

  • Bus route
  • Hour of travel
  • Day of the week
  • Month
  • Weekend indicator
  • Previous day's passenger demand
  • Previous week's passenger demand
  • Seven-observation rolling mean

Output:

  • Predicted passenger demand.
  • Low, Medium or High demand category.
The regression prediction is converted into demand categories using thresholds calculated from the training data.

10. Project Limitations

  • Predictions depend on historical ticketing patterns.
  • Actual onboard occupancy is not directly measured.
  • Unexpected traffic, delays and special events may affect demand.
  • The dataset covers a limited historical period.
  • Predicted demand should be treated as an estimate, not a guarantee.

11. Conclusion

The Crowdedness-Aware Journey Planner demonstrates how machine learning can be applied to historical public transportation ticketing data to estimate passenger demand.

By combining demand prediction, route analysis, peak-hour analysis and smart recommendations, the system provides useful information to support travel planning and data-driven public transportation analysis.
